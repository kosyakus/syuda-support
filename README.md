  # Политика конфиденциальности

  Дата вступления в силу: 6 сентября 2026

  Приложение «Сюда» уважает вашу конфиденциальность.

  ## Какие данные сохраняет приложение

  Приложение позволяет сохранять пользовательский контент:

  - ссылки;
  - текст;
  - фотографии;
  - файлы;
  - голосовые заметки;
  - места;
  - напоминания;
  - коллекции.

  Эти данные сохраняются локально на устройстве пользователя.

  ## Передача данных

  Приложение не передаёт ваши сохранённые данные разработчику.

  Приложение не использует аккаунты, серверную синхронизацию, рекламу или трекинг пользователей.

  ## Разрешения

  Приложение может запрашивать системные разрешения только в момент использования соответствующей функции.

  Например:

  - доступ к фотографиям — для сохранения изображений;
  - доступ к микрофону — для записи голосовой заметки;
  - доступ к геолокации — для сохранения места;
  - разрешение на уведомления — для напоминаний.

  Вы можете изменить разрешения в настройках iOS.

  ## Сторонние сервисы

  Приложение не использует сторонние аналитические или рекламные SDK.

  # Privacy Policy

  Effective date: September 6, 2026

  The Syuda app respects your privacy.

  ## Data Stored by the App

  The app allows users to save personal content:

  - links;
  - text;
  - photos;
  - files;
  - voice notes;
  - places;
  - reminders;
  - collections.

  This data is stored locally on the user’s device.

  ## Data Sharing

  The app does not send your saved content to the developer.

  The app does not use accounts, server sync, advertising, or user tracking.

  ## Permissions

  The app may request system permissions only when you use a related feature.

  For example:

  - Photo Library access — to save images;
  - Microphone access — to record voice notes;
  - Location access — to save places;
  - Notifications permission — to send reminders.

  You can manage permissions in iOS Settings.

  ## Third-Party Services

  The app does not use third-party analytics or advertising SDKs.
